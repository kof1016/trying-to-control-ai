# 整數加法 API

## 功能

提供 `GET /add`，接收 `a` 與 `b` 兩個十進位整數，並以 JSON 回傳兩者相加的精確結果。

## 驗收條件

- [ ] 呼叫 `GET /add?a=1&b=2` 時，回應狀態為 `200 OK`，JSON 內容為 `{"result":"3"}`。
- [ ] `a` 與 `b` 接受符合 `[+-]?[0-9]+`、數字部分為 1 至 1,000 位的 ASCII 十進位整數；正負號不計入位數，前導零計入位數。
- [ ] 1,000 位的運算元可正常相加，結果即使成為 1,001 位仍須精確回傳。
- [ ] 回傳的 `result` 是不含前導零與正號的十進位字串；零一律回傳 `"0"`。
- [ ] 任一參數缺少、不符合 `[+-]?[0-9]+`（例如空字串、小數、指數表示法、非 ASCII 數字或含前後空白的值），或數字部分超過 1,000 位時，回應 `400 Bad Request`。
