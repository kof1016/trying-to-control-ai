# 整數加法 API

## 背景

Repository 需要一個完整、可執行的 A＋B 功能，示範同一份產品契約如何由不同技術棧一致實作。目前 Spring Boot 範例只有應用程式殼，且尚未有 Go Gin 與 NestJS 範例。

## 目標

使用者可在 Spring Boot、Go Gin 與 NestJS 任一範例中，透過相同的 HTTP 介面提交兩個十進位整數，並取得兩者相加的精確結果。

## 驗收條件

- [ ] 在任一範例呼叫 `GET /add?a=1&b=2` 時，回應狀態為 `200 OK`，JSON 內容為 `{"result":"3"}`。
- [ ] `a` 與 `b` 接受可選的正負號及任意位數的十進位整數；結果不因超出 32 或 64 位元整數範圍而失真。
- [ ] 回傳的 `result` 是不含前導零與正號的十進位字串；零一律回傳 `"0"`。
- [ ] 任一參數缺少、空白或不是十進位整數時，回應 `400 Bad Request`。
- [ ] Spring Boot、Go Gin 與 NestJS 範例各自提供可重複執行的自動測試，驗證上述成功與錯誤行為。

## 邊界與錯誤行為

- 可接受的輸入格式為 `[+-]?[0-9]+`，不接受小數、指數表示法、非 ASCII 數字或前後空白。
- 錯誤回應不承諾固定的訊息內容或 JSON 結構。

## 非目標

- 不提供加法以外的算術運算。
- 不支援小數、浮點數、單位換算或運算式解析。
- 不提供圖形使用者介面、身分驗證或持久化紀錄。
- 不承諾三種框架的非公開程式結構一致。

## 技術限制

- 提供 `examples/spring-boot/`、`examples/go-gin/` 與 `examples/nestjs/` 三個可獨立執行及驗證的範例。
- Spring Boot 範例沿用既有 Java 25 與 Maven Wrapper 基線。
- 新增範例分別使用 Go Gin 與 NestJS；各專案須鎖定相依版本並納入 Repository 的 CI 驗證。

## 假設

- 全自動模式沿用 Repository 先前已交付的 `GET /add` 契約，避免因新增技術棧而改變既有公開行為。
- JSON 中以字串表示結果，避免呼叫端的 JSON 數值精度限制破壞任意大小整數。
- 三個範例是同一份契約的平行實作，不互相呼叫，也不需要同時啟動。
