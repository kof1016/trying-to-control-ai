# 整數加法 API

## 背景

Spring Boot 範例目前只有可啟動、可測試的應用程式殼，缺少可供使用者呼叫的產品功能。需要一個最小的加法功能，完整示範從產品契約到交付的 AI-SDLC 流程。

## 目標

使用者可透過 HTTP 提交兩個十進位整數，並取得兩者相加的精確結果。

## 驗收條件

- [ ] 呼叫 `GET /add?a=1&b=2` 時，回應狀態為 `200 OK`，JSON 內容為 `{"result":"3"}`。
- [ ] `a` 與 `b` 接受可選的正負號及任意位數的十進位整數；結果不因超出 32 或 64 位元整數範圍而失真。
- [ ] 回傳的 `result` 是不含前導零與正號的十進位字串；零一律回傳 `"0"`。
- [ ] 任一參數缺少、空白或不是十進位整數時，回應 `400 Bad Request`。

## 邊界與錯誤行為

- 可接受的輸入格式為 `[+-]?[0-9]+`，不接受小數、指數表示法或前後空白。
- 錯誤回應不承諾固定的訊息內容或 JSON 結構。

## 非目標

- 不提供加法以外的算術運算。
- 不支援小數、浮點數、單位換算或運算式解析。
- 不提供圖形使用者介面或持久化紀錄。

## 技術限制

- 功能位於既有的 `examples/spring-boot/` Spring Boot 專案，並沿用該專案的 Java 25 與 Maven Wrapper 驗證基線。

## 假設

- 採用 HTTP API 作為公開介面，以便示範可端到端驗證的產品行為。
- JSON 中以字串表示結果，避免呼叫端的 JSON 數值精度限制破壞任意大小整數。
